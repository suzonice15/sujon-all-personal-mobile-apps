# 04 — Content Rating (IARC questionnaire)

Play Console → **App content → Content rating**. Choose **Education** (or Reference) as the category, then answer:

## Category

```
Education
```

## Questions and answers

| Question | Answer |
|---|---|
| Violence (realistic or fantasy) | No |
| Blood or gore | No |
| Sexual content or nudity | No |
| Profanity or crude humour | No |
| Alcohol, tobacco or drugs | No |
| Gambling or simulated gambling | No |
| Horror or fear elements | No |
| Social features (chat, forums, user profiles) | No |
| Users can interact or share content | No |
| Shares user location | No |
| Allows purchases of digital goods | No |
| Contains ads | **Yes** |
| Unrestricted web access | No |
| User-generated content | No |
| Miscellaneous: does the app contain content that may be unsuitable for children? | No |

## Expected result

- **IARC:** Everyone / 3+
- **PEGI:** 3
- **ESRB:** Everyone
- **USK:** 0

The ads declaration is the only item that can affect the result; ads alone normally still produce "Everyone".

## Notes

1. The app teaches programming. It contains no violence, gambling, substances or sexual content.
2. Course text may mention payment gateways and security attacks (for example SQL injection) in an educational context. This does not change the rating.
3. If you add chat, comments or a public profile later, you must redo the questionnaire and add moderation.
4. If you target children under 13, the Families policy applies and AdMob must serve family-safe ads. The recommendation for this app is **13+**, not Families.
