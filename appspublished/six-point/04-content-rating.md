# 04 — Content Rating (IARC questionnaire)

Play Console → **App content → Content rating**. Choose **Education** (Reference is also acceptable), then answer:

## Category

```
Education
```

## Questions and answers

| Question | Answer |
|---|---|
| Violence (realistic or fantasy) | No |
| Blood or gore | No |
| Sexual content or nudity | No |
| Profanity or crude humour | No |
| Alcohol, tobacco or drugs | No |
| Gambling or simulated gambling | No |
| Horror or fear elements | No |
| Social features (chat, forums, user profiles) | No |
| Users can interact or share content | No |
| Shares user location | No |
| Allows purchases of digital goods | No |
| Contains ads | **Yes** |
| Unrestricted web access | No |
| User-generated content | No |
| Miscellaneous: content that may be unsuitable for children? | No |

## Expected result

- **IARC:** Everyone / 3+
- **PEGI:** 3
- **ESRB:** Everyone
- **USK:** 0

The ads declaration is the only item that can affect the result; ads alone normally still produce "Everyone".

## Notes for this app

1. **Reward box is not gambling.** The daily box and claim rewards are free, need no purchase, and cannot be wagered or cashed out as a bet. Coins can be converted to bKash only through the withdrawal flow, which is a loyalty reward, not a game of chance with stakes. If the box ever becomes paid or wager-based, the answer must change.
2. **Referral screens are not social features.** They show a leaderboard of names and totals from our own server; there is no chat, comment, forum or in-app posting.
3. **Religious content.** The app teaches the six sifat of Tabligh in Bengali. It contains no sectarian attacks, no calls to violence and no political campaigning.
4. **Sharing** uses the Android share sheet to send the Play Store link. That is not in-app user-generated content.
5. **Target audience is 18+** because of the bKash withdrawal feature, even though the content itself is suitable for all ages. This is declared separately in `05-app-content.md`.
6. If chat, comments or public profiles are added later, redo this questionnaire and add moderation.
